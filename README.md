# 回声走廊

校园悬疑互动叙事游戏，46 段剧情、4 个结局。单文件 HTML，用 Twine / Harlowe 3.3.9 构建。

## 在线试玩

开启 GitHub Pages 后访问：

`https://<你的用户名>.github.io/echo-corridor/`

iPhone 上用 Safari 打开后「添加到主屏幕」，可全屏运行。

## 本地运行

直接用浏览器打开 `index.html` 即可，无需服务器、无任何外部依赖。

## 玩法

- 每段文本下方是选择项，点击推进。
- 顶部 HUD 显示线索数、持有道具。
- 进度自动存在浏览器 localStorage，关掉再开可继续。
- 真结局需要同时满足：线索 >= 5、拿到磁带、走通老周线或清单线、三条信任线之一达到 3。
